#109 Показатели команды

Плитки вверху — ссылки на блоки ниже: нажмите, фокус перейдёт на заголовок блока. «Показать причину целиком» и «Показать ещё» работают. Числа — пример.

Что это (коротко)

  • Новая вкладка проекта «Показатели» (/p/:slug/stats) между «Доской» и «Артефактами». Только чтение.
  • Сверху четыре плитки: «В блокерах», «Сбои прогонов», «QA с первого раза», «Готово». Каждая ведёт к своему блоку.
  • Блоки по порядку: «Где застряли» (блокеры с причиной и возрастом) → «Проверки» (круги ревью по PR) → «Спринт» (план, сделано, ещё открыто, по сложности, цикл) → «Прогоны за 14 дней» (по слотам).
  • У каждого блока подписан период: «сейчас», «Sprint 01», «за 14 дней». Переключателя периода нет.
  • Нет данных — пишем «нет данных» и почему. Ноль показываем только там, где это настоящий ноль.
