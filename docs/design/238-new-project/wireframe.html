#238 Новый проект

Кнопки внутри макета работают: они переводят по шагам, как в продукте, и ставят фокус туда, куда его ставит спека. Список выше открывает любое состояние напрямую. Ввода секретов здесь нет нигде, и это намеренно.

Что это (коротко)

  • Мастер «Новый проект» (/new, черновик /new/:id/<шаг>). Шесть шагов: Идея → Интервью → Репозиторий → Подготовка → Окружения → Запуск.
  • Вход: кнопка «Новый проект» на «Все проекты» и в меню проектов, рядом с «Добавить проект» (#194, существующий репозиторий). Незаконченный проект — плитка «Создаётся» вверху «Все проекты».
  • Интервью — вопросы PM по одному, у каждого рекомендованный ответ. В конце бриф. Подготовка (kickoff) получает только бриф, который вы подтвердили.
  • Всё, что пишет в ваш GitHub (создать репозиторий, запустить kickoff, подключить команду), — отдельная кнопка с подтверждением. Удалять репозиторий консоль не умеет.
  • Окружения: только статусы «Задано / Не задано / Отсюда не видно». Значения вводятся на экране «Настройка окружения» (#104), не в мастере.
