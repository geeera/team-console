#277 Дизайны прямо в консоли

Нажмите на дизайн в списке. В просмотрщике: стрелки ← → на клавиатуре, свайп на телефоне, Esc закрывает.

Как показываем безопасно. Картинки (PNG, JPEG, WebP, GIF; не SVG) консоль получает через api Worker, привязанные к коммиту, и показывает в <img>. Так работают и приватные репозитории. HTML-вайрфрейм открывается только во вкладке «Интерактивно», в <iframe sandbox="allow-scripts"> без allow-same-origin, и только с разрешённого адреса GitHub Pages проекта (embed-origins, #20). srcdoc и HTML с адреса консоли не используем никогда. Подробнее — в спеке на #277.
