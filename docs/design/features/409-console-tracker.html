Team Console · #409 · design for approval

Tasks and sprints in the console

What you are approving

What you are approving. Only what the UX spec on #409 marks NEW or CHANGED (wireframe in PR #413), in Paper Desk, iPhone first, then the Mac, light and dark, ru and en. Everything else is #107, #108, #16, #29 and #114 as you approved them.

Task names follow ADR 0006. A task is TC-410 everywhere (row, menu, slip, task screen, receipt, Find); a pull request is PR #415; an old GitHub number keeps its # and always says GitHub (“Was GitHub #410 ↗”). The spec’s bare #n is replaced by this throughout. Find accepts 142, #142, TC-142 and a pasted GitHub link.

  • Board row (changed). The row opens the task in the console. A ⋯ button sits at the row’s right edge, 44 px, its own tab stop, never inside the link. All future sprints are folders: the first says “Next sprint”, the rest “Later”. After them lies a blank folder, a dashed outline of the next folder with Create a sprint. With no future sprint, the Next strip says so and has the same button. The request slip, the partial backlog and GitHub’s 429 are gone.
  • Move menu (new). A paper slip under ⋯ on the Mac, a bottom action sheet on the iPhone, the same items in both. Every sprint shows “4 tasks · demo Nov 27”. “It’s here now” and a frozen current sprint stay in the list, focusable, with a ring or lock and their reason in AA text. A full sprint keeps its item; only the hint turns ochre (“Already 9 tasks: the team usually finishes 8”). The queue items (First, Up, Down) have their own heading with the lane. A task in progress gets an ochre note at the top.
  • After a move. The row fades and drifts 12 px (240 ms), then the list reflows at once. An ink Undo slip appears: “TC-408 → Sprint 04 · Undo ⌘Z”, with a moss hairline that runs down the 10 s and stops while you hover or focus it. Up / Down / First keep the row in its lane, and the paper under it glows moss once. If a move fails, a clay block sits at the top of that section, with Try again.
  • Task screen (new). A sheet of paper: the key and kind as a typed tab, the title in the serif (h1), Edit. Below is a ledger of fields with small-caps labels. Status, Kind and Sprint are underlined values you can press (Sprint opens the Move menu). Queue, Tier, Labels and Opened by are plain, and Opened by carries “Was GitHub #n ↗”. Then Details in the serif, and History on a margin rule: author and time first, your entries in moss, PR links by branch in mono. The comment box is a ruled card at the end. The Mac shows the task in a 480 px pane beside the board (#114’s pane, wider) and the row stays marked. On the iPhone it is its own page with “‹ Board”.
  • Pickers (new). The same slip / sheet as the Move menu, as radio items: each value with its one-line meaning, and “usually the team” on In progress and QA. Picking saves at once. The value inks moss for a moment, and History gets the line.
  • Edit, conflict and errors. Edit turns the title and details into #107’s fields (serif title, counters at 80 %), with Save ⌘↩ and Cancel. A restored draft is #107’s ochre margin slip. “Changed while you were editing” is ochre, not clay, because nothing is lost: Show their version opens the PM’s text, read-only, under the field. Failures (403, no connection, no answer) are #107’s clay blocks. Offline after load is a quiet sunken line at the top, and every write control says why it is off.
  • Decision. #16’s card as it is (question, “The team recommends”, Approve / Reject). Approve presses the ink stamp and leaves #16’s margin receipt, “Approved · TC-345 · 14:05 · the team reads it on its next run”. A /approve line in a comment shows the note under the box, so a comment is never taken as a decision. Closed: the title is struck through in a hairline, with a quiet note and Reopen, and there is no comment box.
  • Create a sprint (changed #29). #107’s dialog / sheet frame: Name in the serif, prefilled “Sprint 06”, the date, and a moss-ruled note that works out the start and the freeze days as you change the date. Errors sit above their field. On success the new folder opens, takes focus and glows once (#108’s arrival).
  • New task (changed #107). The project list keeps storify but off, with the lock note. Each place says the status it sets (“· as Approved”, “· as Proposed”). The receipt card reads TC-413, “In Sprint 04, 10th in the queue.”, and Open the task. The Connect block, the public-repository and command notes and the GitHub errors are gone.
  • Find (new). A page with a ruled search field (/ on the Mac, ⌕ on the iPhone). Results are one index list: key in mono, title in the serif with the matched words in moss, kind · status · sprint or “closed”. A link to another project is a moss margin note with Open GH-12 in ghost. A link to a project not moved yet is a grey note linking to GitHub.
  • Move storify to the console (new). A banner on that project’s board: a white sheet with a moss rule. Then a three-step strip (Copy · Check · Switch) that runs the whole flow. Copying shows a ledger with a real progress bar. The check is a ruled table: GitHub against the console, “matches” with a tick, a mismatched row in ochre with “differs”, never colour alone. Failures are a clay list, and Switch stays off with its reason. The confirm is an alertdialog with the four lines numbered and Not yet first. Switching ticks off five lines in ink. A failed switch is clay and says nothing is lost. Switched stamps the project card (Paper Desk’s ink stamp).

QA notes from PR #413, addressed here: keys TC-n and PR #n. First focus: Create sprint on Name, the reject sheet on its reason field, pickers on the checked option, the discard and switch confirms on their heading. The “Was GitHub #n” link’s accessible name starts with its visible text (WCAG 2.5.3). ru plurals use one / few / many (“1 открытая”, “4 задачи”, “Уже 9 задач”). An off item’s reason is --text-2 on the surface (AA in both themes), never faded by opacity. After Try again, focus waits on the task’s h1 (or the section heading on the board) and then goes to the action’s own target.

Try it on iPhone: press ⋯ on TC-408, pick Sprint 04, then Undo. Open TC-395 and change its Status. Pick “TC-345 waits for you” and Approve. Set the next write to “changed meanwhile” and save an edit. Pick Screen → Move storify and press Make the copy.

Colour
Paper Desk tokens only. Ink (--text on --bg) for the Undo slip and the open menu button. Moss (--accent, --accent-soft) for your history entries, a landed row, a matched word, the import banner rule and the stamp. Ochre (--warning-*) for a full sprint, the in-progress note, the conflict and a mismatched count. Clay (--danger-*) for failures, --bg-sunken for offline. Off items use --text-2; contrast is AA in both themes.
Type
Source Serif 4 for titles, details, comments and the sprint name. Source Sans 3 for the UI, small caps for the ledger labels. Source Code Pro for keys and branches. No new fonts.
Tokens
Proposed for the kit: --task-pane-w 480 px, --menu-w 320 px, --undo-ms 10 s, --ledger-label 112 px. Everything else exists (--target, --r-*, --sp-*, --shadow-*, --dur-*, --folder-tab-*, --stamp-sm).
Kit
Reused as is: #108’s sections and Disclosure, #134 tc-lanes, #107’s Sheet, fields, tseg/topts and receipt card, #16’s card and receipt, the confirm alertdialog, StateBlock. New in the kit before the feature uses it: Menu (popover / action sheet; menuitem and menuitemradio, off items with a reason), UndoToast (role=status, pause on hover/focus, ⌘Z), Ledger (a dl of label / value rows), PickerButton (the value inside its name, aria-haspopup=menu).
Motion
Menu: 140 ms fade + 4 px drop (sheet: 380 ms rise). Leaving row: 240 ms fade + 12 px, then no height animation. Landed row and changed value: a 1.6 s moss glow. Pane: 380 ms slide-in of 16 px. Stamp: Paper Desk’s. With reduced motion everything is a 120 ms fade or nothing: no drift, no glow, no stamp motion, no Undo hairline, and static skeletons and rings. Only opacity, transform and background animate.

Что вы утверждаете. Только то, что UX-спека #409 отметила как НОВОЕ или ИЗМЕНЁННОЕ (вайрфрейм в PR #413), в стиле Paper Desk: сначала iPhone, потом Mac, светлая и тёмная тема, русский и английский. Всё остальное — #107, #108, #16, #29 и #114 в утверждённом вами виде.

Задачи называются по ADR 0006. Задача везде — TC-410: в строке, меню, плашке, на экране задачи, в квитанции и в поиске. Пул-реквест — PR #415. Старый номер с GitHub оставляет # и всегда говорит «GitHub» («Была на GitHub: #410 ↗»). Где в спеке стоял просто #n, теперь так. Поиск понимает 142, #142, TC-142 и вставленную ссылку с GitHub.

  • Строка доски (изменено). Строка открывает задачу в консоли. Справа кнопка ⋯ — 44 px, отдельная остановка Tab, не внутри ссылки. Все будущие спринты — папки: первая подписана «Следующий спринт», остальные «Позже». За ними лежит пустая папка — пунктирный контур с кнопкой «Создать спринт». Если будущих спринтов нет, полоска «Следующий» говорит об этом, и кнопка там же. Полоски просьб, неполный бэклог и 429 от GitHub убраны.
  • Меню переноса (новое). На Mac — листок под ⋯, на iPhone — лист снизу. Пункты одинаковые. У каждого спринта строка «4 задачи · демо 27 ноя». «Сейчас здесь» и замороженный текущий спринт остаются в списке и получают фокус: у них кольцо или замок и причина текстом с контрастом AA. Полный спринт не блокируется — только подсказка становится охристой («Уже 9 задач: команда обычно успевает 8»). У пунктов очереди («Первой», «Выше», «Ниже») свой заголовок с названием дорожки. Если задача в работе, сверху охристая заметка.
  • После переноса. Строка гаснет и сдвигается на 12 px (240 мс), список сразу перестраивается. Появляется чернильная плашка «Отменить»: «TC-408 → Sprint 04 · Отменить ⌘Z». По её низу 10 секунд бежит тонкая зелёная линия; она останавливается, пока на плашке курсор или фокус. «Выше / ниже / первой» оставляют строку в её дорожке, и бумага под ней один раз подсвечивается зелёным. Если перенос не прошёл, наверху раздела появляется блок цвета глины с «Повторить».
  • Экран задачи (новое). Лист бумаги: ключ и тип как печатный ярлык, название с засечками (h1), кнопка «Изменить». Ниже — ведомость полей с подписями капителью. Статус, Тип и Спринт — подчёркнутые значения, на них можно нажать (Спринт открывает меню переноса). Очередь, Сложность, Метки и Автор — просто текст, у Автора ссылка «Была на GitHub: #n ↗». Дальше Подробности с засечками и История на линии полей: сначала автор и время, ваши записи зелёные, PR со своей веткой моноширинным. В конце — поле комментария, разлинованная карточка. На Mac задача открывается панелью 480 px рядом с доской (панель #114, шире), строка на доске остаётся отмеченной. На iPhone — отдельная страница с «‹ Доска».
  • Выбор значения (новое). Тот же листок или лист снизу, что у меню переноса, с пунктами-переключателями. У каждого значения — смысл одной строкой, у «В работе» и «Проверка» — пометка «обычно команда». Выбор сохраняется сразу: значение на миг подсвечивается зелёным, в Истории появляется строка.
  • Правка, конфликт и ошибки. «Изменить» превращает название и подробности в поля #107: название с засечками, счётчики от 80 %. Кнопки «Сохранить ⌘↩» и «Отмена». Восстановленный черновик — охристая заметка на полях из #107. «Задача изменилась, пока вы её правили» — охра, а не глина: ничего не потеряно. «Показать их версию» открывает текст PM под полем, только для чтения. Сбои (403, нет связи, нет ответа) — блоки цвета глины из #107. «Нет сети после загрузки» — тихая утопленная строка наверху, а каждая кнопка изменения объясняет, почему выключена.
  • Решение. Карточка #16 как есть: вопрос, «Команда советует», «Утвердить» / «Отклонить». «Утвердить» ставит чернильный штамп, и остаётся заметка на полях из #16: «Утверждено · TC-345 · 14:05 · команда прочитает на ближайшем прогоне». Если в комментарии есть строка /approve, под полем появляется пояснение: комментарий не считается решением. Закрытая задача: название перечёркнуто тонкой линией, тихая заметка и «Вернуть в работу», поля комментария нет.
  • Новый спринт (изменено #29). Окно / лист в рамке #107: Название с засечками, заранее «Sprint 06», дата и заметка с зелёной чертой — она сама пересчитывает начало и дни заморозки, когда вы меняете дату. Ошибки стоят над своим полем. После создания новая папка открывается, получает фокус и один раз подсвечивается (как в #108 по ссылке).
  • Новая задача (изменено #107). В списке проектов storify остаётся, но выключен, с пояснением и замком. У каждого варианта места видно, какой статус он ставит («· статус «Одобрено»», «· статус «Предложено»»). Карточка-квитанция: TC-413, «В Sprint 04, 10-я в очереди.» и «Открыть задачу». Блок подключения GitHub, заметки про публичный репозиторий и команды, ошибки GitHub убраны.
  • Поиск (новое). Страница с разлинованным полем (/ на Mac, ⌕ на iPhone). Результаты — один список-картотека: ключ моноширинным, название с засечками, найденные слова подсвечены зелёным; тип · статус · спринт или «закрыта». Ссылка на другой проект — зелёная заметка на полях с «Открыть GH-12 в ghost». Ссылка на ещё не перенесённый проект — серая заметка со ссылкой на GitHub.
  • Перенос storify в консоль (новое). Плашка на доске проекта: белый лист с зелёной чертой. Дальше полоска из трёх шагов (Копия · Сверка · Переключение) — по ней идёт весь перенос. Копирование — ведомость с настоящим индикатором progress. Сверка — разлинованная таблица «GitHub / консоль»: «совпадает» с галочкой, несовпавшая строка охристая и со словом «не совпадает», не только цветом. Ошибки копии — список цвета глины, «Переключиться» выключено с причиной. Подтверждение — alertdialog: четыре пронумерованные строки, «Пока нет» первым. При переключении пять строк по очереди отмечаются чернилами. Неудача — блок цвета глины, в нём сказано, что ничего не потеряно. «Переключено» — штамп Paper Desk на карточке проекта.

Замечания QA из PR #413, учтены: ключи TC-n и PR #n. Первый фокус: «Новый спринт» — на Названии, лист отказа — на поле причины, выбор значения — на отмеченном пункте, подтверждения отмены правки и переключения — на заголовке. Доступное имя ссылки «Была на GitHub: #n» начинается с видимого текста (WCAG 2.5.3). Русские числа по формам one / few / many («1 открытая», «4 задачи», «Уже 9 задач»). Причина у выключенного пункта — --text-2 на поверхности (AA в обеих темах), без прозрачности. После «Повторить» фокус ждёт на h1 задачи (на доске — на заголовке раздела), а потом переходит туда, куда ведёт само действие.

Цвет
Только токены Paper Desk. Чернила (--text на --bg) — плашка «Отменить» и открытая кнопка меню. Мох (--accent, --accent-soft) — ваши записи в истории, строка на новом месте, найденное слово, черта на плашке переноса, штамп. Охра (--warning-*) — полный спринт, заметка «в работе», конфликт, несовпавшее число. Глина (--danger-*) — сбои, --bg-sunken — нет сети. Выключенные пункты — --text-2, контраст AA в обеих темах.
Шрифты
Source Serif 4 — названия, подробности, комментарии, имя спринта. Source Sans 3 — интерфейс, подписи ведомости капителью. Source Code Pro — ключи и ветки. Новых шрифтов нет.

Панель: въезд на 16 px за 380 мс. Штамп — Paper Desk.
