Team Console · #238 · design for approval

New project: from an idea to a working team

What you are approving

What you are approving. How the New project wizard looks and moves (#238): from a few sentences about an idea to a team working on it, iPhone first, then the Mac, light and dark, ru and en. Flow, states and copy come from the UX spec on #238 (wireframe in #343) with the architect note of 15 Oct applied: the repository comes before the interview, because the interview is the new project’s own PM chat. So the steps are Idea → Repository → Interview → Kickoff → Environments → Start.

  • Two doors on All projects. New project (moss, primary) and Add a project (outlined) sit together under the title, with one line explaining which is which. A draft is a sheet still on the desk: a dashed tile on surface paper with “Being created”, the step, what it waits on in moss (“The PM is waiting for your answer”), a six-part ink rule and Continue. With no projects, the empty block offers both doors.
  • The wizard is a dossier. On the Mac: the title and the draft line, six numbered marks on one ruled line (done ones are links with a tick, the current one is underlined in moss), the step on the left and a project card on the right: a ruled index card that fills in as you go (idea, repository, brief, kickoff, environments). On the iPhone: “Step 2 of 6 · Repository”, the same ink rule in six parts, and All steps to unfold the list. Back to All projects is top left; ⋯ → Cancel creating is top right while it is allowed.
  • Idea. One big plain textarea, a counter, your GitHub account line, Next: repository. Nothing is created before you press it.
  • Repository. You type the name after a fixed geeera/; it is checked as you type (“The name is available” in moss, or the reason in clay with a way to “Add a project” instead). Private and Public are two large radio cards with their consequence. A sunken “What happens” box lists the writes, and in ochre the one step that stays yours: giving the team app and the review app access. Create the repository asks once (sheet). Then a ledger of four rows (repository, console app, team apps, project in the console) inks in one by one. A row that needs you is outlined in ochre with the word and the links; a failed one is clay with the word and Retry for that row only. If the console may not create repositories, Create on GitHub opens the prefilled form and the step waits and rechecks.
  • Interview. Your idea goes in as the first chat message. Seven topics sit on top as small tags: moss with a tick when settled, dashed while open. The PM’s question is a letter: small caps meta, the question in the serif, “Why I ask” in italic, the recommendation on a moss margin, up to three one-tap answers, then Accept the recommendation / Answer differently. Earlier answers fold away as margin notes with Change. While the PM thinks, your answer stays as a note and a dashed “The PM is working on the next question…” block says you can close the app. A comment from someone else in that chat is marked “Not from the team” in a dashed ochre frame.
  • The brief is a typed sheet. Version and time on top, field names in small caps, your answers in the serif, the PM’s assumptions on an ochre dashed margin. A field you changed is underlined in moss in version 2. Looks right: continue freezes it; the lock line says so.
  • Kickoff is one button, one sheet, then seven stage rows that ink in, each done row with “Open ↗”. Stalled is an ochre banner (no restart), stopped is a clay block with Continue kickoff. At the end, a moss card “Waiting for you: 3” leads to Needs you.
  • Environments shows names and statuses only: never a value, never a field. The ochre dashed summary says how many are missing; the primary button opens Environment setup (#104); Skip for now says what that means.
  • Start: one more sheet, then the signature moment: a large moss ink stamp “Started” presses onto the card, its rings and tick draw in, beside “The team is working on chess-coach”.

Try on iPhone: All projects → New project, type an idea, Next, type a name (try team-console), Create, Next: interview, Start the interview, Accept or pick a one-tap answer, Change something in the brief, confirm, Start kickoff, Next, Skip for now, Start the team. Tick “The console can’t create repositories” to see the GitHub link path. The bar reaches all 46 states.

For the team, not for this approval: with the project registered at the end of step 2, “Cancel creating” is offered on steps 1–2 only; from the interview on, leaving is just navigating away and the project can be archived like any other. The UX designer confirms or moves this in the spec.

Colour
Paper Desk tokens only. Moss (--accent*) for the next action, the current step, settled topics, the recommendation margin and the stamp; ochre (--warning-*) for “needs you”, PM assumptions, the missing summary and “Not from the team”; clay (--danger-*) for failures and Cancel; --surface-2 and a dashed edge for a draft. Every state is a word plus an icon, and the needs-you and failed rows also have an outline. Text pairs are AA in both themes.
Type
Source Serif 4 for the PM’s voice, the brief and titles; Source Sans 3 for the interface and your own text; Source Code Pro for repository and secret names. All OFL; no new fonts.
Tokens
Proposed: --wiz-main-w 600, --wiz-aside-w 272, --wiz-seg-h 3, --wiz-step-mark 24, --stamp-lg 120, --ta-min 148 px. Everything else exists: 44 px target, spacing, radii, --r-sheet, --scrim, durations.
Kit
New: Stepper (marks on a rule; compact form with All steps), Textarea in Field with a counter, RadioCard group, a Ledger on List (states done / in progress / waiting / needs you / failed / later), an option-chip button. Reused: Sheet.confirm (#282 footer order), Recommendation, Receipt, Banner, StateBlock, Button, Field.
Motion
Step change: content fades and rises 6 px, the current mark presses in. Ledger rows ink their tick in order. A new question rises 6 px; the settled topic draws its tick. The stamp presses (rotate −24° → −9°, 240 ms) and its strokes draw (≈370 ms). Reduced motion: 120 ms fades, static skeleton and dots, the stamp only fades.

Что вы утверждаете. Как выглядит и двигается мастер «Новый проект» (#238): от пары предложений об идее до команды, которая над ней работает. Сначала iPhone, потом Mac, светлая и тёмная тема, русский и английский. Сценарий, состояния и тексты — из UX-спеки в #238 (вайрфрейм в #343), с учётом заметки архитектора от 15 октября: репозиторий создаётся до интервью, потому что интервью идёт в собственном чате PM нового проекта. Поэтому шаги такие: Идея → Репозиторий → Интервью → Подготовка → Окружения → Запуск.

  • Две двери на «Все проекты». «Новый проект» (мох, главная кнопка) и «Добавить проект» (контурная) стоят рядом под заголовком, а строка под ними объясняет разницу. Черновик — лист, который ещё лежит на столе: плитка с пунктирным краем, пометка «Создаётся», шаг, чего он ждёт (мхом: «PM ждёт вашего ответа»), чернильная линейка из шести частей и кнопка «Продолжить». Если проектов нет, пустой блок предлагает обе двери.
  • Мастер — это папка с делом. На Mac: заголовок и строка черновика, шесть пронумерованных отметок на одной линейке (пройденные — ссылки с галочкой, текущая подчёркнута мхом), слева шаг, справа карточка проекта — разлинованная карточка, которая заполняется по ходу: идея, репозиторий, бриф, подготовка, окружения. На iPhone: «Шаг 2 из 6 · Репозиторий», та же линейка из шести частей и «Все шаги», чтобы раскрыть список. Слева вверху — назад во «Все проекты», справа — ⋯ → «Отменить создание», пока отмена возможна.
  • Идея. Одно большое простое поле, счётчик, строка с вашим аккаунтом GitHub и «Дальше: репозиторий». До нажатия ничего не создаётся.
  • Репозиторий. Имя вводится после неизменного geeera/ и проверяется по ходу ввода: «Имя свободно» мхом или причина глиной — со ссылкой «Добавить проект», если такой репозиторий у вас уже есть. «Приватный» и «Публичный» — две крупные карточки-переключателя с последствиями. В углублённом блоке «Что сделаем» перечислены записи, а охрой — единственный шаг, который остаётся за вами: доступ приложению команды и приложению ревью. «Создать репозиторий» спрашивает один раз (лист). Дальше журнал из четырёх строк (репозиторий, приложение консоли, приложения команды, проект в консоли) прорисовывается по одной. Строка, где нужен ваш шаг, обведена охрой, со словом и ссылками; строка со сбоем — глиной, со словом и кнопкой «Повторить» только для неё. Если консоли нельзя создавать репозитории, «Создать на GitHub» открывает уже заполненную форму, а шаг ждёт и проверяет сам.
  • Интервью. Идея уходит первым сообщением в чат. Сверху семь тем маленькими ярлыками: мох с галочкой — ясно, пунктир — ещё нет. Вопрос PM выглядит как письмо: служебная строка капителью, вопрос с засечками, «Почему спрашиваю» курсивом, рекомендация на зелёном поле, до трёх ответов в одно касание, затем «Принять рекомендацию» / «Ответить иначе». Предыдущие ответы сворачиваются в заметки на полях с кнопкой «Изменить». Пока PM думает, ваш ответ остаётся заметкой, а пунктирный блок «PM думает над следующим вопросом…» говорит, что приложение можно закрыть. Комментарий постороннего в этом чате помечен «Не от команды» в пунктирной охристой рамке.
  • Бриф — напечатанный лист. Сверху версия и время, названия полей капителью, ваши ответы с засечками, допущения PM — на охристом пунктирном поле. Поле, которое вы поправили, в версии 2 подчёркнуто мхом. «Всё верно — дальше» фиксирует бриф, о чём говорит строка с замком.
  • Подготовка — одна кнопка, один лист, затем семь строк этапов, которые прорисовываются по очереди; у готовой строки есть «Открыть ↗». «Давно нет новостей» — охристый баннер (без перезапуска), «остановилась» — блок глиной с кнопкой «Продолжить подготовку». В конце зелёная карточка «Ждут вас: 3» ведёт в «Ждёт вас».
  • Окружения показывают только имена и статусы: никаких значений и полей ввода. Охристая пунктирная сводка говорит, сколько не задано; главная кнопка открывает «Настройку окружения» (#104); «Пропустить пока» объясняет, что это значит.
  • Запуск: ещё один лист, затем фирменный момент — крупный зелёный чернильный штамп «Запущено» прижимается к карточке, кольца и галочка прорисовываются рядом с «Команда работает над chess-coach».

Попробуйте на iPhone: «Все проекты» → «Новый проект», напишите идею, «Дальше», введите имя (попробуйте team-console), «Создать», «Дальше: интервью», «Начать интервью», примите рекомендацию или выберите ответ в одно касание, поправьте бриф, подтвердите, «Запустить подготовку», «Дальше», «Пропустить пока», «Запустить команду». Включите «Консоль не может создавать репозитории», чтобы увидеть путь через ссылку на GitHub. Панель открывает все 46 состояний.

Вопрос команде, не для этого согласования: раз проект регистрируется в конце шага 2, «Отменить создание» есть только на шагах 1–2; с интервью уйти из мастера — просто перейти на другой экран, а проект можно отправить в архив, как любой другой. UX-дизайнер подтвердит это в спеке или поправит.

Цвет
Только токены Paper Desk. Мох (--accent*) — следующее действие, текущий шаг, ясные темы, поле рекомендации и штамп; охра (--warning-*) — «нужен ваш шаг», допущения PM, сводка «не задано» и «Не от команды»; глина (--danger-*) — сбои и отмена; --surface-2 с пунктирным краем — черновик. Каждое состояние — слово и значок, а у строк «нужен ваш шаг» и «не удалось» ещё и обводка. Контраст текста AA в обеих темах.
Шрифты
Source Serif 4 — голос PM, бриф и заголовки; Source Sans 3 — интерфейс и ваш текст; Source Code Pro — имена репозиториев и секретов. Все под OFL, новых шрифтов нет.
Токены
Предлагаются: --wiz-main-w 600, --wiz-aside-w 272, --wiz-seg-h 3, --wiz-step-mark 24, --stamp-lg 120, --ta-min 148 px. Остальное уже есть: цель касания 44 px, отступы, скругления, --r-sheet, --scrim, длительности.
Кит
Новое: Stepper (отметки на линейке; компактный вид с «Все шаги»), Textarea в Field со счётчиком, группа RadioCard, Ledger на основе List (готово / идёт / ждёт / нужен ваш шаг / не удалось / позже), кнопка-вариант ответа. Повторно: Sheet.confirm (порядок кнопок #282), Recommendation, Receipt, Banner, StateBlock, Button, Field.
Движение
Смена шага: содержимое проявляется со сдвигом 6 px, текущая отметка «вдавливается». Строки журнала прорисовывают галочки по порядку. Новый вопрос поднимается на 6 px, у ясной темы рисуется галочка. Штамп прижимается (поворот −24° → −9°, 240 мс), кольца прорисовываются (≈370 мс). При «Меньше движения» — затухание 120 мс, неподвижные скелетон и точки, штамп только проявляется.
